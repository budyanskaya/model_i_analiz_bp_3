# Моделирование и анализ бизнес процессов
## Задание 3
*Сценарий:* Регистрация нового клиента в системе

Описание: Менеджер получает данные клиента → проверяет уникальность email → создаёт учётную запись → отправляет приветственное письмо → процесс завершён.
Задание в StormBPMN:
- Создайте процесс Регистрация клиента – [Фамилия].

Смоделируйте последовательность в BPMN 2.0:
- Start Event (Message) → User Task → Service Task → Send Task → End Event.
- Добавьте пул с двумя дорожками: Менеджер и Система.

## Решение
<img width="1322" height="648" alt="image" src="https://github.com/user-attachments/assets/cf637313-2b00-4894-8a07-e2e12552a5dd" />

На диаграмме представлен процесс регистрации нового клиента в системе с участием менеджжера и системы. Процесс начинается с получения заявки менеджером, который запрашивает данные у клиента. Затем данные передаются в систему для проверки на уникальность. Система проверяет, является ли email уникальным: если email уже существует, система отправляет сообщение об ошибке менеджеру, который связывается с клиентом для уточнения корректных данных, после чего процесс проверки повторяется. Если email уникален, система создаёт учётную запись клиента и автоматически отправляет ему приветственное письмо. Процесс завершается успешной регистрацией нового клиента в системе. Диаграмма демонстрирует взаимодействие между менеджером и системой, включая обработку ошибок и циклическую проверку данных.
